# FieldSure AI — Data Intake Directory (`data/`)

This directory is designated for authoritative public health guidance documents, outbreak protocols, and clinical advisories.

## Supported Formats
- **PDF Documents** (`.pdf`): Clinical manuals, official gazettes, vaccine inserts.
- **Word Documents** (`.docx`): Protocol drafts, standard operating procedures (SOPs).
- **Markdown** (`.md`): Formatted guidance, operational checklists.
- **Plain Text** (`.txt`): Raw advisories, public health bulletins.

## Privacy & Security Notice
- Files in this directory are excluded from version control via `.gitignore`.
- **Zero PHI/PII Policy**: Field workers and developers must never place documents containing Protected Health Information (PHI) or Personally Identifiable Information (PII) into this directory.
- Only official public health agency documents (e.g., WHO, CDC, Ministry of Health) should be stored here.
