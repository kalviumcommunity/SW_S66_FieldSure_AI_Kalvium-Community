# Similarity Search & Top-K Retrieval Sample

## Sample configuration

- **Query:** `How can field workers prevent dengue?`
- **Configured embedding model:** `illustrative-test-model`
- **Query vector dimension:** 8
- **k values compared:** 2 and 5
- **Collection:** `sample_retrieval`

The workspace did not contain `outputs/embedded_chunks.jsonl` or API
credentials. To exercise the complete vector-store search path with the
prepared 11-chunk corpus, this sample uses clearly illustrative 8-dimensional
vectors and a mocked query embedding. These are not generated by a live
embedding model and the scores do not represent semantic evaluation. For real
retrieval, the configured `EMBEDDING_MODEL` must match the model used to
generate and index the corpus vectors.

## Results

Similarity is calculated as `1 - cosine_distance`, using ChromaDB's cosine
distance collection. Results are returned in descending similarity order.
