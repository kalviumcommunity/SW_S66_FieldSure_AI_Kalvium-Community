The smoke test uses a small illustrative vector to verify that local ChromaDB
is reachable, stores a vector with its source text and metadata, and returns the
same record after readback. It is not an embedding generated by the configured
model. The collection dimension is inferred from the first inserted vector.
Use `uv run python -m src.vector_db_demo` to load the corpus vectors produced by
`src.embed_corpus` into the configured production collection.
